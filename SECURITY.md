# Security and publication boundaries

This repository is a **standalone portfolio demonstration**, not the app source or production backend.

No production keys, Supabase project URLs, authentication tokens, identifiers, RevenueCat configuration, live prompts, unpublished client data, or private repository history are included.

The JavaScript examples have no dependencies, network requests or database connections. They run only on invented data.

**Do not** paste production environment files, complete server exports, service role keys, developer provisioning profiles or private app assets into this repository. Do not reuse the sample response validator in a production service without additional bounds, authorization, quotas and comprehensive testing.

Ingredient exclusion checks are imperfect and cannot guarantee allergy safety. This repository does not offer medical or dietary safety assurance.

For security concerns, use the [portfolio contact page](https://barbarakprokop.com/productdesign/) rather than publishing suspected credentials in a GitHub issue.
